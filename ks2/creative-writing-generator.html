How to Use This Tool

Generate a full story idea (character, setting, problem, object and mood, plus an optional opening line), then write. If you like one element but want to change the rest, lock it first, then generate again -- only the unlocked elements will change. Writing challenges and timers are entirely optional extras for pupils who want an added focus or a bit of pace. This tool never marks, scores or judges any writing -- it's a springboard for ideas, not an assessment.
