Examiner tips (how to use revision time well)

These habits are what move grades, not just "reading notes".

Retrieval first
  • Start with a question (flashcard / quiz / past paper item).
  • Mark it → fix the gap → re-test 48–72 hours later.
Past paper routine
  • Timed section → mark scheme → "error log".
  • Redo the same skill next week (that's how marks improve).
Don't revise evenly
  • Strong topics need maintenance (small doses).
  • Weak topics need repetition (bigger doses).
Make it measurable
  • Tick tasks off daily.
  • Track completion % weekly.
  • Change the plan when the data changes.
